Changelog

What changed, release by release

What an investigator notices in each release: the features added and the bugs fixed. Housekeeping and internal work is left out. The next public release is planned and not yet released; it is described on the download page.

Since 0.11Internal builds, not yet released
Added
  • Evidence: drop a PDF or any file onto an object or the Evidence tab; captured material as tiles in a grid; an item form in four headed sections; replace an item's image or file without losing the work around it; link evidence to an object or a timeline event by picking, from either side; your own categories; text extracts keep their structure from paste to report.
  • Figures: tick an image or a text extract to carry it into the report with a caption and cross-reference links.
  • Timeline: time precision and zone, named clocks, source, status, phases and your own columns; durations as bars; import events from a spreadsheet; focus a span, compress gaps, arrange cards so none overlap; portrait view with the event table alongside; a portrait page export; links to the map and the evidence.
  • Map: objects closed as undetermined are drawn hatched, with Show, Fade or Hide controls; Arrange lays the map out lane by lane with arrows pointing left to right; zoom out to 5 per cent.
  • Analysis: one rule for finalising an object, with Close as undetermined where the findings policy allows it and one Unresolved matters section in the report; Importance is tested after an inconclusive Influence; a record check warns when Influence passes without Existence established.
  • Dashboard: completeness tiles above the checklist and the to-do list, each with a jump to the work. Jump to the map from a to-do, an evidence item's use or a record check.
  • Draft report: its own tab, with Draft my report, step plans and time left for each AI run, audit, repair and polish as separate steps, redraw a section, per-claim audit actions, a Stop control, and the report edited in place. A review copy carries the audit and check marks as plain-language Word comments.
  • AI: reasoning effort for each endpoint and role, usage, cost and timing for each run in the Log, and a User Guide list of exactly what is sent to a model and what never is.
  • Reports and exports: Evidence and Argument Tables with a contents page, one table per page and numbered argument points; report styles each described with its length and an example; the map, timeline and tables as optional appendices; built-in report looks; Save as PDF; the working record exported by part or by section; every file labelled IWS or IWS (AI).
  • People and names: a People register, who is who from the interviews, Replace names with roles, an optional AI check of the corrected transcript against the audio, an interview summary, a per-investigation abbreviations list and a Names & Abbreviations page.
  • Probability wording: the likelihood bands and their accepted phrases adjustable in Settings; the object form shows what a slider position reads as.
  • Admin & Comms with a starter set of seven email templates for any industry, and a Details tab for the facts that fill every cover.
  • Files: new investigations save as .iwsx and interview files as .iwsi; existing .sfm files keep opening and saving under their own name.
  • Settings reorganised and the AI access and Models pages redesigned; a fictional-case label on every document; a Windows-style menu bar and slimmer tab bar; an Example report (PDF) and the User Guide illustrated throughout, with every control explained.
  • Interviews: each interview has an Interview page for before and during it (the invitation, attendees, preparation, a notepad, and the interview guide beside the notepad), alongside its Record page; the record's interview summary can be drafted with AI.
  • Standard of proof: Pass, Inconclusive and Fail bands, set in Settings as the default for new investigations, recorded in each investigation and stated in every drafted report.
  • Settings: pages regrouped into two bands and renamed, a Shared practice page for the organisation's policies, a padlock on a page that is locked as a whole, and one save rule.
  • Names & Abbreviations: one To decide list and four Decided lists.
  • The maker named: Investigation Workflow Suite is made by Synoptic Safety Investigation Software.
Fixed
  • Saving is safer: one save coordinator, a file is replaced safely, a new investigation never overwrites an existing one, closing never discards without a choice, and Overwrite keeps the other investigator's version as a copy. Every edit is an undo step, and typing no longer saves the whole file on every keystroke.
  • Record checks read only the sentence that restates a factor's own claim, leave excluded hypotheses and other risk factors unconnected by design, and read a numbered Findings list item by item.
  • Drafting keeps numbers true to the record, never assigns a gender the record does not state, holds back unfinalised or out-of-date sections, and treats a refused or wrong-shaped AI reply as a failed pass, never as the report.
  • The finished report is written without gap markers, and a dropped connection to an AI endpoint is retried.
  • A crash shows a screen instead of a blank window; embedded files open safely and the app makes no external image requests.
  • The command-line export carries figures like the app's own export, and User Guide passages that described old behaviour are corrected.
  • A copied email pastes with the template's own paragraph gaps.
  • Typing in what a timeline duration spans, or in a terms of reference line, no longer lags behind the keyboard, and each edit is one undo step.
  • Help's object key says an excluded hypothesis comes only from a failed Existence test.
0.11.030 September 2026

Since changed: the trial is 90 days, exports carry no watermark, and the tier then called Standard is now Free.

Added
  • Six report styles: standard, three-page preliminary update, executive brief, and three final-report styles modelled on published investigation reports.
  • Repair against the audit: flagged sections sent back with the record excerpts, re-audited, and landed one at a time.
  • Probability wording per band and finding terms, adjustable in Settings; the confidence slider offers 5 and 95.
  • Evidence items as read-only cards edited in a full form, with Finalise and Reopen.
  • Interview note windows and a Finalise that renders the record as one document; Teams transcripts import from docx or vtt.
  • The investigation log records the app's own actions with a timestamp.
  • Reports carry a contents page, section page breaks and an activity appendix.
  • Signed licences with a 30-day trial; an unlicensed copy runs as the then-Standard tier with a watermark.
Fixed
  • The record check reads findings through their subheadings and compares like with like.
  • Notations from the scaffold no longer leak into report prose.
  • Word's leftover instances after a PDF run are closed by the publishing script.
0.10.029 September 2026

Since changed: the training build was withdrawn. There is one standard build.

Added
  • Two standard builds, generic and training, each as an installer and a portable exe.
  • Interviews are a record: import a Teams transcript (docx or vtt) or type notes, keep the investigator's notes beside it, name people by role, and mark it final. Drafting uses the finalised record as the interview's evidence.
  • The checklist and interview templates are written for any investigator and edited in Settings.
  • The standard of proof presets are named by what they mean, from the balance of probabilities at 50 per cent to very likely at 90.
Fixed
  • Object forms open at about 80 per cent of the window, so a long argument is readable without resizing.
  • The Checklist tab's to-do column is wide enough to read a to-do with its source line.
0.9.127 September 2026
Added
  • Shared folders: a save that would overwrite another investigator's changes is held, with reload, copy or overwrite as the choices, and a lock file beside the open investigation tells the other person it is in use.
  • Causal map: Shift+click adds to the selection, Shift+drag draws a selection box, and the selection drags as one.
  • Object forms carry a to-do list, and every to-do appears on the Checklist tab with a link back to its object.
Fixed
  • Settings panes scroll on their own, so a long pane no longer scrolls the dialog behind it.
0.9.025 September 2026
Added
  • Editable abbreviations lists in Settings, with import, merge, export and a reset to the shipped list.
  • Glossary sets chosen per interview, so only the terms that appear in the record are sent to a model.
