Getting started

Your first investigation

Investigation Workflow Suite (IWS) is laid out the way an investigation runs. These are the steps for a first one; the user guide covers each in full.

  1. Install and open IWS. On first run, start the 90-day Professional trial or carry on as Free.
  2. Create the investigation with File, New investigation, named for the occurrence. IWS makes a folder holding the investigation file.
  3. Work the checklist: answer the triage questions, log the decision to investigate and set the standard of proof.
  4. File the evidence as it arrives, each item once with its source, and build the timeline from it.
  5. Record the interviews and finalise each account once it is settled.
  6. Build the map: place the critical event, then a factor for every event or condition that might have played a part.
  7. Test each factor for Existence, Influence and Importance, with the confidence behind each result, and connect the causal chains.
  8. Export the Evidence and Argument Tables, and draw off the report in the style required.

Learn from a finished one

The start screen opens a worked example investigation, and the case studies show complete investigations from first notification to final report.
