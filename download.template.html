Before you install

The first launch of a new build can trigger a Windows SmartScreen prompt. Choose More info, then Run anyway.

IWS sends nothing about an investigation anywhere unless AI access is set to Endpoint, and then only to the server you configured. The endpoint settings and the drafting controls say where an action would send investigation text off the machine. Starting the Professional trial sends the email address you give and an identifier for the computer to the licence server, and nothing about any investigation.

The 90-day trial

A new installation can start 90 days of Professional from first run. Starting it needs the computer online once; offline, IWS works as Free and the trial can be started later. When the 90 days are up, IWS carries on as Free, and a Professional licence turns the features back on. To buy one, talk to us.

Your investigations are never locked

A licence decides which features are available, never whether you can open your own work. Every existing investigation opens and stays workable in Free, whatever licence it was started under.

How AI connects, and where each AI access setting sends data, is set out on the AI and security page.
