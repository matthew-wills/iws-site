Before you install

The first launch of a new build can trigger a Windows SmartScreen prompt. Choose More info, then Run anyway.

IWS sends nothing about an investigation anywhere unless AI access is set to Endpoint, and then only to the server you configured. The endpoint settings and the drafting controls say where an action would send investigation text off the machine.

AI access

Three AI access modes, depending on how your organisation wants to use a model

The record, the map, the tests and the report assembly are the application in every mode. The mode sets how much model work sits on top of them, from none at all to a configured endpoint. Standard runs with AI access set to No AI.

No model required

Standard

For an investigation with no model involved.

  • Checklist, evidence, interviews, timeline, causal map
  • Evidence and Argument Tables, map and timeline exports
  • Reports assembled from the record, in any style
Investigator-mediated AI

Chat

Copy a prompt out to a chat tool you are entitled to use, and paste the reply back.

  • Everything in Standard
  • Section and whole-report prompts, built from the record
  • Pasted drafts land, are checked, and can be finalised
Integrated model access

Endpoint

A configured model: local, an organisation gateway, or a hosted API with your own key.

  • Everything in Chat
  • Section and whole-report drafting and checks inside the application
  • Record checks on every draft

An unlicensed copy runs as the Standard tier with an evaluation watermark; a 30-day trial licence turns everything on.

Organisations: a custom build carries your own framework, templates, report style and workflow, licensed to your investigators, with the application underneath unchanged.

Where each mode sends data, and what stays on the machine, is set out on the AI and security page.

Students and educators

The training edition

The training edition carries public teaching material and an educational watermark on exports. It is the build to use for coursework.
